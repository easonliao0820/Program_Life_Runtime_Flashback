# 還缺的圖

## 四象限版面 `assets/ui/split/`

### 開場
```
我要幫一款像素風的視覺小說＋寫程式遊戲畫「介面外框」。畫面分成四塊：左上劇情、右上程式碼、左下任務卡、右下執行結果。四個框要是同一套設計，我們一張一張來，之後每一張都請遵守：

1. 像素風，像素清楚不要糊，線條乾淨
2. 配色固定：深海軍藍 #1E2A38、捷運藍 #2D529E、暖金色 #F8D08D、米白 #FFFAF0
3. 外框粗細四邊一樣，大約 6～8 像素：外面一圈深藍、裡面一條 1～2 像素的金色細線，四個角各有一個小小的金色方形鉚釘
4. 框的中間一定要是「單一平塗的顏色」，不要任何花紋、格線、電路、漸層、陰影（遊戲會把中間拉伸）
5. 裝飾只能放在四個角落，不要放在邊的中間
6. 不要文字、浮水印、按鈕、立體透視
7. 去背（框外面是透明的）

先回覆「了解」，還不用畫。
```

### frame_code.png
```
程式碼編輯區的外框，128×128，正面平視。照開場的外框規則：深藍外框＋金色細線＋四角金色鉚釘。中間平塗深夜藍色 #161F2B，像關燈的程式編輯器。左上角的框上加一排三個小圓點（紅、黃、綠，各 3 像素），像程式視窗的標題列。中間不要任何東西。
```

### frame_output.png
```
執行結果區的外框，128×128，和 frame_code 同一套外框（深藍外框＋金色細線＋四角金色鉚釘）。中間平塗更深的黑藍色 #10161F，像終端機畫面。左上角的框上加一個小小的綠色「▶」符號（5 像素大），代表執行。中間不要任何東西。
```

### frame_task.png
```
任務卡的外框，128×128，和 frame_code 同一套外框（深藍外框＋金色細線＋四角金色鉚釘）。中間平塗溫暖的米白色 #FFFAF0，像一張乾淨的任務紙卡。右上角的框上加一個小小的捷運藍色書籤緞帶（往下垂 10 像素左右）。中間不要任何東西。
```

### frame_story.png
```
劇情畫面的外框，128×128，和 frame_code 同一套外框（深藍外框＋金色細線＋四角金色鉚釘），但是框的中間是「完全透明」的（會疊在劇情畫面上面，像一個相框）。框的內側邊緣加 1 像素的淡淡暗影，讓畫面看起來嵌在框裡。
```

### split_backdrop.png
```
介面後面的底圖，256×144，不要去背，整張都要有顏色。深海軍藍 #1E2A38 的平面，上面有非常淡的像素點格紋（比底色只亮一點點，幾乎看不出來），右下角有很淡的捷運路線圖線條（細細的藍色與金色線、幾個小圓點站名，不要文字）。整體要很安靜、低對比，不能搶前面四個框的注意力。
```
