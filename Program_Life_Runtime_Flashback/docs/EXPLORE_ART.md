# 探索模式（側向）要生的圖

探索模式有 3 關：2.1 回憶盒子、3.1 整理書包、3.4 學測行前檢查。畫面是**側面看的房間**，主角左右走、上下樓梯。

- 圖還沒放進來時，遊戲會用色塊頂著，**現在就能玩**。
- 圖照檔名放進 `assets/explore/` 就會自動換掉色塊，不用改程式。
- 背景放進去之後跟我說：家具、樓梯、物品的位置要跟背景圖對齊。數字在 `src/game/core/explore_layouts.gd`，我會幫你對。

不用從頭玩就能試玩：

```
godot --path . res://tests/explore_preview.tscn -- --level=ch3_1
```

`--level=` 可以換成 `ch2_1`、`ch3_1`、`ch3_4`。

背景的實際解析度跟 CG 一樣，用你的方案生得出來的就好（640×360、480×270、256×144 都可以）。**只要比例對**（16:9；3.1 是 32:9），遊戲會自己放大。

> 角色動畫的格子規則：**sprite 一律面向右邊**，往左走時遊戲會自己翻轉。腳要踩在格子的最下面，每一格的腳底高度都一樣。
> 匯出成 GIF 或多列的 sheet 時：`python3 tools/make_sheet.py 檔案 -o 輸出.png`（多列加 `--grid 4x2`）。

## 開場（附上參考圖一起送）

要附的圖：`assets/backgrounds/my_room.png`（風格參考）。

```
我要幫一款像素風的視覺小說遊戲畫「側面看的房間」小遊戲的美術，主角會在房間裡左右走、上下樓梯找東西。我們一張一張來，之後每一張都請遵守：

1. 像素風，像素清楚不要糊，畫風跟我附的圖一致
2. 場景在台灣（2000～2010 年代）：鋁窗、鐵窗、磁磚地、透天厝，不要日式或韓式
3. 視角是「正側面剖面」，像橫向卷軸遊戲：看得到地板那一條線，家具都貼著地板排成一排，不要俯視、不要斜角
4. 地板要是一條清楚、水平的線，角色會站在上面走
5. 不要畫任何人，不要文字、浮水印、邊框
6. 角色和物品的小圖要去背（透明背景）

先回覆「了解」，還不用畫。
```

## 背景

### 1. `explore_house.png`（3.1，1280×360）

> 劇情：睡過頭了，要在捷運進站前整理好書包出門。主角從 2 樓房間出發，走樓梯下 1 樓，從右邊的大門出去。巧克力在 1 樓最左邊的冰箱，跟大門是反方向。

做不到 1280 寬的話，分成**左半**、**右半**兩張 640×360 生，再用 `python3 tools/make_sheet.py 左.png 右.png -o explore_house.png` 接起來。兩張的地板高度要一樣。

```
一張很寬的台灣透天厝「剖面圖」，正側面看，兩層樓，早上的陽光。從左到右：
【2 樓，畫面上半部，只佔左邊一半】最左邊是高中生的房間：一張單人床（藍色床單）、木頭書桌、靠牆的書架；房間右邊接著一段走廊，走廊盡頭是往右下走的樓梯。
【1 樓，畫面下半部，整個寬度】最左邊是廚房（冰箱在最左邊、流理台），接著是餐廳（一張餐桌），樓梯從 2 樓走廊斜斜地往右下接到 1 樓中間，再往右是客廳（紅色沙發、矮茶几、電視），最右邊是玄關（鞋櫃、大門）。
2 樓地板是一條清楚的水平橫線，在畫面高度 45% 左右；1 樓地板在畫面最下面 5% 的地方。樓梯是清楚的一階一階。2 樓右半邊（樓梯右邊的上方）是客廳挑高的牆面。
```
```
（分兩半生時，左半）同上面的描述，只畫左半邊：2 樓的房間＋走廊，1 樓的廚房＋餐廳。640×360。
```
```
（分兩半生時，右半）同上面的描述，只畫右半邊：樓梯從左上斜到下面中間，1 樓的客廳和玄關大門；上半部是客廳挑高的牆。640×360。地板高度要跟左半張一模一樣。
```

### 2. `explore_living_room.png`（2.1，640×360）

> 劇情：1 歲的你在家裡爬來爬去，發現很多發光的回憶盒子。高櫃子上的盒子太高了，要推小板凳過去。

```
台灣老公寓的客廳，正側面看，午後溫暖的陽光從窗戶照進來，是 1 歲小孩眼中又大又溫暖的家。從左到右：最左邊靠牆是一個高高的木頭櫃子（櫃子上面有一層平台，大約在畫面一半高的地方）；接著是通往廚房的門；中間是一張矮矮的布沙發；沙發上方的牆上有一扇大鋁窗；右邊是木頭電視櫃，上面放著一台舊的映像管電視。地板是米色磁磚，是畫面最下面的一條水平線。不要畫人，不要畫小板凳。
```

### 3. `explore_bedroom_dawn.png`（3.4，640×360）

> 劇情：學測當天清晨，天還沒亮，房間很暗。（遊戲會自己把畫面調暗，只有主角身邊看得到，背景照正常亮度畫就好。）

```
高中生的房間，正側面看，清晨天剛亮，窗外是淡粉紅和淡藍色的天空，室內是微弱的晨光。從左到右：一張單人床（枕頭在左邊）、床旁邊一個小床頭櫃（有抽屜）、一張木頭書桌（有抽屜，桌上堆著參考書），書桌上方的牆上有窗戶；書桌右邊是一個矮櫃，矮櫃上方的牆上釘著一層置物架；再右邊是房門；最右邊牆上的掛勾掛著一件外套。地板是畫面最下面的一條水平線。不要畫人，不要畫椅子。
```
